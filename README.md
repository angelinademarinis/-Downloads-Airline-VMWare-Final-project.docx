World of Aviation Network Security Design

Project Overview

This project involves designing a secure and fault-tolerant network for an aviation domain using VMware. It demonstrates the implementation of key security measures and advanced network configurations to ensure operational resilience and protection against cyber threats.

Key Features

Active Directory Design: Implemented with Organizational Units (OUs) to manage users and groups effectively.

Security Controls: Integration of security measures such as:

Anti-Malware (AMG 01)

Spam filtering appliances

Wireless Intrusion Prevention System (WIPS)

Network Access Control (NAC)

Email security gateway

Network Design: Created network diagrams showcasing fault tolerance, defense in depth, and segmentation across domains like American Airlines, United, Southwest, Delta, and JetBlue.

Threat Mitigation: Strategies to protect against:

Malware

Phishing

Spam

Non-company-owned devices

Rogue access points

Tools & Technologies Used

VMware: For virtual environment setup and testing.

Windows Server: Active Directory, GPO configurations, and DNS/DHCP management.

Network Security Appliances: Configured within the VMware environment.

Deliverables

Network Diagram: Visual representation of the network's architecture.

Configuration Documentation: Step-by-step setup of the security appliances and server configurations.

Screenshots: Timestamped images of implemented configurations and outputs.

Learning Objectives

Understand and implement Defense in Depth strategies.

Use VMware to simulate real-world network environments.

Apply Active Directory for structured management of resources.

Enhance networks with fault tolerance and advanced security measures.

Future Improvements

Incorporate additional monitoring tools for real-time threat detection.

Explore automation for repetitive security tasks.

Enhance scalability to support larger domains.

Conclusion

This project demonstrates a comprehensive approach to designing and securing a network for the aviation industry, emphasizing robust configurations and proactive threat management.
